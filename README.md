## What is this?

[DataLemur](https://datalemur.com/) is a technical interview preparation platform specializing in SQL, Data Analytics, and Data Science interview questions.

This repository contains solutions to DataLemur problems using **SQL**, covering fundamental-to-advanced database concepts and analytical query techniques commonly tested in technical interviews.

---

## SQL

DataLemur provides a collection of SQL interview questions designed to develop practical database querying, data manipulation, and analytical problem-solving skills.

The practice covers core SQL concepts including:

- Basic Queries
- Filtering (`WHERE`)
- Sorting (`ORDER BY`)
- Aggregate Functions
- `GROUP BY`
- `HAVING`
- `JOIN` Operations
- Subqueries
- Common Table Expressions (`CTEs`)
- `CASE` Expressions
- NULL Handling
- Date & Time Functions
- String Functions
- Window Functions
- Ranking Functions
- Running Totals & Cumulative Aggregations
- Advanced Analytical Queries
